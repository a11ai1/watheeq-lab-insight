# وَثيق WATHEEQ LAB AI

أنشئ مشروعًا جديدًا باسم «وَثيق» من الوصف المتاح، وتجاوز الصورة المرجعية غير المرفقة الآن.

أريد إعادة تصميم مشروع **وَثيق | WATHEEQ LAB AI** اعتمادًا على الصورة المرجعية المرفقة، بحيث يكون التصميم قريبًا جدًا منها من حيث الألوان، وتقسيم الواجهة، والبطاقات، والرسوم البيانية، والفخامة التقنية.

**الهدف:** تحويل المشروع إلى نظام مراقبة مختبرات ذكي يبدو كمنتج طبي تقني عالمي، وليس موقعًا تعريفيًا أو نموذجًا جامعيًا تقليديًا.

### 1. التصميم والهوية

- اعتمد الصورة المرفقة مرجعًا أساسيًا للتصميم (Visual Reference).
- استخدم خلفية كحلية داكنة متدرجة مع إضاءات سماوية وبنفسجية.
- اجعل البطاقات بتأثير زجاجي خفيف (Glassmorphism) وحدود مضيئة ناعمة.
- استخدم رسومًا بيانية متقدمة ومتنوعة بألوان Cyan وPurple وBlue.
- صمّم شعارًا احترافيًا ومميزًا باسم **وَثيق | WATHEEQ LAB AI**.
- واجهة عربية بالكامل RTL، باستخدام خط عربي حديث وواضح.
- قائمة جانبية على اليمين، وشريط علوي منظم.
- توزيع دقيق للشاشات والبطاقات مثل الصورة المرجعية، دون ازدحام أو فراغات غير ضرورية.
- حركات بسيطة عند التفاعل وتحديث البيانات، دون مشاهد 3D أو مؤثرات مبالغ فيها.

### 2. الشاشات الرئيسية

أنشئ نظامًا متكاملًا يتضمن:

1. **لوحة التحكم:** أرقام العينات، الحالات الحرجة، العينات المكتملة، الرسوم البيانية، ومؤشرات الأداء.
2. **المراقبة المباشرة:** نتائج CBC تصل لحظيًا وتُرتب حسب الخطورة.
3. **التحليل الذكي:** تفسير نتائج العينات واكتشاف القيم الحرجة والأنماط غير المعتادة.
4. **تفاصيل العينات:** جدول التحاليل، المجالات المرجعية، الرسوم البيانية، والتوصيات المخبرية للتحقق.
5. **مركز التنبيهات:** الحالات الحرجة وإجراءات الأخصائي.
6. **أجهزة المختبر:** حالات الأجهزة الافتراضية ونشاطها.
7. **الإحصائيات والتقارير:** رسوم ومؤشرات تفاعلية متقدمة.
8. **المحاكاة المباشرة:** تشغيل عينات تجريبية ومشاهدة تحليلها وتصنيفها.

### 3. لوحة التحكم الرئيسية

اجعلها أكثر شاشة جاذبية، وبنفس روح التصميم المرفق.

أريد بطاقات إحصائية بأرقام كبيرة، ورسوم Bar Charts وLine Charts وDonut Charts وRadial Progress، ومؤشرات دائرية، ورسوم توضح توزيع العينات ومعدل معالجة النتائج.

خصص جزءًا بارزًا للحالات الحرجة، يعرض رقم العينة وقيمتها وسبب التنبيه وزر مراجعتها.

اجعل جميع الرسوم مترابطة ببيانات المحاكاة الحقيقية، وليست عناصر زخرفية أو أرقامًا عشوائية.

### 4. التفاعل والمحاكاة

أضف زر **«تشغيل المحاكاة»**.

عند الضغط عليه، تبدأ نتائج CBC اصطناعية بالوصول، وتتحدث الأرقام والرسوم تلقائيًا. عند اكتشاف نتيجة حرجة، يظهر تنبيه أحمر راقٍ، وتنتقل العينة إلى أعلى الأولويات، ويمكن فتح تفاصيلها وتوثيق مراجعة الأخصائي.

جميع الأزرار والجداول والتنبيهات والفلاتر يجب أن تعمل فعليًا.

### 5. الجودة النهائية

أريد تصميمًا بمستوى **Premium Enterprise Medical Dashboard**، قريبًا للغاية من الصورة المرجعية، مع هوية أصلية لوَثيق.

لا تستخدم صور مختبرات ضخمة، أو مجسمات 3D، أو صفحات طويلة مليئة بالكلام.

**التركيز على الشاشات الاحترافية، والرسوم البيانية، وكثافة المعلومات المنظمة، وجمالية الهوية البصرية.**

احفظ وظائف المشروع الحالية وأعد تصميم جميع شاشاته بشكل متناسق، مع بيانات اصطناعية واضحة ومناسبة للعرض أمام لجنة تحكيم MEDATHON 2026.
