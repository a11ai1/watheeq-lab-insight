# وَثيق | WATHEEQ LAB AI

**منصة ذكية للمراقبة والتحليل اللحظي لنتائج المختبرات الطبية.**

يهدف مشروع «وَثيق» إلى تعزيز سلامة المرضى ورفع كفاءة العمل المخبري، من خلال تحليل نتائج فحوصات الدم (CBC) باستخدام الذكاء الاصطناعي، واكتشاف القيم الحرجة والأنماط غير الطبيعية، وترتيب الحالات حسب الأولوية لدعم سرعة مراجعتها واتخاذ القرار.

يوفر النظام لوحة تحكم تفاعلية، ومراقبة مباشرة للنتائج، وتنبيهات ذكية، وتقارير تحليلية، بالإضافة إلى بيئة محاكاة ببيانات اصطناعية لعرض آلية عمل النظام.
